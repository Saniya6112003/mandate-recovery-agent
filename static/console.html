UPI Autopay Mandate Recovery

When an automatic UPI payment fails, this agent works out why, decides what to do about it, and has that decision checked against RBI compliance rules before anything happens. Every step below is recorded and cannot be edited afterwards.

How a failed payment moves through the system

Each case runs through all five stages. Stage 3 can overrule stage 2.

1Payment failsThe bank returns a decline code, e.g. Z9 = not enough money.
2AI diagnosesReads the code and history, gives a cause, a plan, and how sure it is.
3Rules check itFixed compliance code that can refuse the AI's plan. It always wins.
4Action runsUsually a real Razorpay payment link sent to the customer.
5OutcomeMarked recovered only when a verified bank webhook confirms payment.

Can we trust how confident the AI says it is?

The AI reports a confidence score with every answer. We checked whether that score actually predicts being right.

Why this matters: if confidence doesn't tell us when the AI is wrong, we can't let it authorise payments on its own. That is exactly why stage 3 is ordinary code with fixed rules — it doesn't care how certain the AI sounds.
